Content Gallery

The merged replacement for the Preset Catalog, Custom Content Catalog, and browsing side of Preset Explorer — one card grid for every custom unit/building found across the project, with real stat diffs vs. vanilla, raw code, and which saved presets each one is already in. Mark items you're considering; picking/injecting into a live preset is still done in Preset Explorer on purpose, kept as a deliberate separate step. Rebuild data with node ../custom-content-database/build-database.js.
